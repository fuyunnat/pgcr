# PGCR — Audi A4L B9 / MHI2Q P0915 Mirror Lab

This repository develops reversible MMI Mirror tuning for Audi A4L B9 with `MHI2Q_CN_AUG22_P0915`.

Initial goal: keep the verified V2.2 runtime unchanged and tune only the supported geometry profiles (`scale` / `offset`) so larger Virtual Cockpit rendering can be tested safely.

Upstream base: `Lanye-z/MHI2Q-CarPlay-RGI-MMI-Mirror`.

Development happens on feature branches. Do not flash unreviewed builds to a vehicle.
